.image-wrapper:hover img {
    filter: none; /* Removes the grayscale */

How this works:
The Tint: The .image-wrapper has a solid teal background. We apply mix-blend-mode: multiply and filter: grayscale(100%) to the image itself. This strips the color from your photo and blends it with the background block, creating that perfect monotone look.

The Square: We use ::after on the wrapper to create a fake box with a 2px border. We use position: absolute with top: 20px and left: 20px to push it out from exactly behind the image.

The Hover: When you hover over the wrapper, the CSS drops the filters (returning the image to its natural color) and uses transform: translate() to gently push the image and the border in opposite directions.
