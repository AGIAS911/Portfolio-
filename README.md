# Personal Portfolio Website

A personal developer portfolio website showcasing my skills, experience, projects, and contact information.

## About
This portfolio was created to present my journey as a Computer Information Systems graduate and aspiring full-stack developer. 
It includes sections for:
- About Me
- Skills
- Experience
- Projects
- Contact

## Technologies
- HTML5
- CSS3
- Responsive Web Design
- Font Awesome

## Features
- Responsive design for desktop, tablet, and mobile
- Fixed navigation header
- Smooth scrolling
- Interactive experience tabs
- Project cards with hover effects
- Social media links
- Contact form
- CSS animations and transitions
- Mobile-friendly layout

## Getting Started
1. Clone the repository:
   ```bash
   git clone https://github.com/AGIAS911/Portfolio.git
   ```
2. Open the project folder.
3. Navigate to the `project` folder and open `index.html` in your browser.

*No additional installation or dependencies are required.*
